No proxy of your own yet? The Your own proxy server page shows how to rent a VPS, run one command and get an HTTPS proxy with a password and a ready line for Routekeeper. Without the password, such a server answers like an ordinary web server. So scanners don’t find an open proxy, and strangers can’t use it.
