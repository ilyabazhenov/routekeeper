License: a Mac’s code and its key

Routekeeper routes traffic only with a valid license. A license is tied to one Mac and usually lasts a year. It is checked on the Mac itself, with no network requests.

A license is a long string of letters and digits issued for your Mac’s code. You paste it into Settings → License once, and again only to renew it or to move to another Mac.

What works without a license

Without a license you can install and set up all of Routekeeper: the welcome screen, proxies, your own server, apps and services, rules. It just doesn’t route traffic: the Routekeeper On switch doesn’t turn on, and every app connects directly, as if Routekeeper weren’t there. So you can set everything up while you wait for the license.

Getting and entering a license

  1. Find this Mac’s code. Open Settings → License. The code looks like RK-7K3M-Q9TD-2XHA. Until there’s a license, it’s also on the welcome screen.
  2. Send the code to Routekeeper’s author. Click Copy and paste the code into an email or a message. If you read the code out loud: it never has the letters O, I or L, those are the digits 0 and 1.
  3. Paste the license you get. The reply is a long string. Paste it into the Paste the license field and click Activate. Line breaks and spaces added by mail or a messenger don’t matter.
  4. Check the switch. If the license turned Routekeeper off (there was none yet, or it ended), it turns back on by itself. If you turned it off yourself, turn it on with the Routekeeper On switch in the menu bar icon’s menu or in the window.

If a license doesn’t fit, the text under the field says why: it wasn’t copied in full, it’s for another Mac, or it has already ended. A license that doesn’t fit isn’t saved and doesn’t replace the one you already have.

Term and renewal

A license is valid through the date shown in Settings → License, inclusive. The date is in Coordinated Universal Time (UTC): in New York the last day ends at 7 or 8 p.m. local time.

14 days before the end, a reminder with a Renew… button appears on the Overview and in the menu bar icon’s menu, and macOS shows a notification 14, 7, 3 and 1 day before. To renew, send the Mac’s code again and enter the new license over the old one.

When a license ends, Routekeeper turns itself off within a minute. The network extension does this, so it happens even when Routekeeper’s window and icon are closed. If Routekeeper is running, macOS shows a notification. Rules, proxies and settings stay: when you enter a new license, Routekeeper turns back on.

When Routekeeper is off, nothing goes through a proxy. Apps connect directly, and websites see your real IP. Renew the license before it ends.

Another Mac

A license works only on the Mac with the code it was issued for. If you move Routekeeper to another Mac, for example with Migration Assistant, Settings → License says The license is for another Mac. Send the new Mac’s code and enter the new license.

The code stays the same when you update or reinstall macOS or replace the disk or memory. It changes after a logic board replacement and in a virtual machine.

More: how the check works

A license is a signed string: a name, an email (if given), the Mac’s code, and the issue and end dates. Its Ed25519 signature is checked with a public key built into Routekeeper, with no network requests: at launch, every hour, after sleep and when you come back to Routekeeper. Only the author has the private key that signs licenses, so the name, code or date in a license can’t be changed.

The Mac’s code is 60 bits of the SHA-256 hash of the Mac’s hardware identifier (IOPlatformUUID), written in letters and digits. The identifier itself goes nowhere.

The license is kept in the keychain, in the “Routekeeper license” item, and a copy is in the network extension’s settings, which only an administrator can reach. The extension checks it by itself every half minute, whether Routekeeper’s window is open or not.

Time doesn’t go backward for the license: Routekeeper remembers the latest time it has seen, and setting the clock back, even by a day, doesn’t extend a license. If the clock once jumps far ahead, that moves the count by a day at most: once the clock is fixed, the license works again.
