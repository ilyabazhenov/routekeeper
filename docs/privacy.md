# Политика конфиденциальности

Действует с первой публичной версии Routekeeper.

Коротко: **Routekeeper не собирает данные о вас и вашем трафике и никуда
их не отправляет.** Всё, что он знает о ваших соединениях, остаётся
на вашем Mac.

## Что Routekeeper видит

Чтобы решать, куда направить соединение, системное расширение Routekeeper
видит о каждом исходящем соединении:

- какой процесс его открыл: путь, подпись, родительские процессы;
- куда: адрес, порт, протокол и имя хоста, если приложение его передало;
- сколько данных прошло, сколько это заняло и чем закончилось.

Содержимое соединений Routekeeper не читает. Трафик, который идёт через
прокси, он передаёт как есть, не расшифровывая.

## Где это хранится

| Что | Где | Сколько |
|---|---|---|
| Журнал соединений для монитора | В памяти системного расширения, последние несколько тысяч записей | До перезапуска расширения. На диск не пишется. |
| Правила, список прокси, настройки, пароли прокси | Файл конфигурации системного расширения, доступен только root | Пока вы их не удалите. Остаётся после удаления приложения, чтобы правила вернулись при повторной установке. |
| Служебные логи | Системный журнал macOS (unified logging) | Сколько их хранит macOS, обычно несколько дней. |

Окно Routekeeper получает настройки **без паролей прокси**.

Служебные логи содержат технические события: включение, ошибки, решения
по соединениям. В них могут попасть адреса, к которым обращались приложения.
Логи не покидают Mac, пока вы сами не приложите их к сообщению об ошибке.

## Куда Routekeeper ходит в сеть сам

- **На ваши прокси** — передавать трафик приложений, которым вы назначили
  маршрут через прокси.
- **На ipinfo.io через ваш прокси** — только когда вы нажимаете «Проверить»:
  чтобы показать задержку, адрес и страну, которые видят сайты. Запрос идёт
  через прокси, поэтому ipinfo.io видит адрес прокси, а не ваш.
- **На GitHub за обновлениями** — когда в приложении появится автообновление.
  Запрос анонимный: в нём только версия Routekeeper.

Больше никуда. Никакой аналитики, телеметрии, отчётов о сбоях,
рекламных идентификаторов.

## Ваши прокси

Трафик, который вы направили через прокси, видит владелец прокси-сервера.
Routekeeper за него не отвечает: выбирайте прокси, которым доверяете.

## Если вы пишете нам

Сообщение об ошибке в GitHub Issues публично. Перед тем как приложить лог,
просмотрите его и уберите то, что не хотите показывать.

## Изменения

Если политика изменится, новая версия появится в этом файле, а история
изменений — в истории репозитория.
